# UniCloud

Comprehensive Lifecycle Network Management platform

[Go UniCloud](http://unicloud.ethernexion.com/)

## One Unified Platform for Next-Gen Network Management

UniCloud is an independently developed solution by Ethernexion, designed for enterprise networks, campus networks, and SMB network environments. It provides comprehensive management functionalities—from ZTP (Zero Touch Provisioning) deployment to device onboarding, device monitoring, remote configuration and maintenance, OTA upgrades, panel simulation, configuration rollback, and template-based configuration.

![UniCloud unified management platform overview](https://www.ethernexion.com:8001/media/original_images/DiDuoBianXingKeJiFengZhiHuiChengShiGuanKongChaHua_2.webp)

Automate ZTP, visual topologies, and simulation control via one smart platform.

- ![](https://www.ethernexion.com:8001/media/original_images/BuShuJiaGouQuanJingTu.png)

### Flexible Deployment Architecture

Supports both public cloud and internal LAN deployment on a unified software platform.

- ![](https://www.ethernexion.com:8001/media/original_images/YunBuShu.png)

### Zero-Touch Provisioning (ZTP)

Enables automated device onboarding, configuration, and rapid service launch.

- ![](https://www.ethernexion.com:8001/media/original_images/TaPuGouWang.png)

### Automatic Topology Discovery

Automatically discovers network topology and generates visualized topology maps.

- ![](https://www.ethernexion.com:8001/media/original_images/gd3.png)

### Simulation Panel Control

Provides simulation-based panel for centralized control and operations.

- ![](https://www.ethernexion.com:8001/media/original_images/ShiShiJianKong.png)

### Real-Time Monitoring

Delivers continuous network status monitoring for improved visibility.

- ![](https://www.ethernexion.com:8001/media/original_images/ZuoCeDaoHang_ZuZhiJiaGou.png)

### Multi-Organization Support

Supports both multi-organization and single-organization modes simultaneously.

### Graphical simulation panel

UniCloud adopts a graphical simulation panel for operation, providing customers with an unparalleled operational experience.

![UniCloud graphical simulation panel](https://www.ethernexion.com:8001/media/original_images/U1.webp)

### Automatic TOPO discovery and drawing

UniCloud automatically discovers network nodes based on the neighbor discovery protocol and automatically generates a network topology map.

![Automatic network topology discovery in UniCloud](https://www.ethernexion.com:8001/media/original_images/U2.webp)

### Multi-network domain management

UniCloud supports multi-domain network management and assigns different management permissions to different network domains.

![Multi-network domain management in UniCloud](https://www.ethernexion.com:8001/media/original_images/U3.webp)

### Intelligent PoE network energy management

Support the energy planning function and provide programmable capabilities for the PoE energy network.

![Intelligent PoE energy management in UniCloud](https://www.ethernexion.com:8001/media/original_images/U4.webp)
